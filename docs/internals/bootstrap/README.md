## 🚀 Quick Start

```bash
# Build Palladium using itself!
cd bootstrap/v3_incremental
./tiny_v16 tiny_v16.pd > tiny_self.c
gcc -o tiny_self tiny_self.c
./tiny_self test.pd

# Or use the full compiler
cd bootstrap/v2_full
../v3_incremental/tiny_v16 pdc.pd > pdc.c
gcc -o pdc pdc.c
./pdc your_program.pd
```

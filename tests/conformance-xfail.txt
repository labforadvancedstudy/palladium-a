# Conformance expected-failure manifest, read by scripts/conformance.sh.
#
# Format:  <path relative to repo root><whitespace><reason>
# Comments (`#`) and blank lines are ignored. A reason is mandatory.
#
# An entry here means "this program is known not to work, and we know why".
# It does NOT soften the gate:
#   - a listed file that fails    -> XFAIL, and the reason is printed on every run
#   - a listed file that PASSES   -> XPASS, and the gate FAILS (delete the entry)
#   - a listed file that does not exist, or is skipped -> STALE, and the gate FAILS
#
# So an entry can only ever be paid off, never forgotten.
